The rules that are not negotiable

These are the kit's prohibitions. They are checked mechanically, not remembered — a colour literal that is not in the token file fails the check.

no colour-transition gradients no photography in the system itself no hue outside the token file no icons beyond geometric primitives no webfont not declared in the kit no animation beyond 120ms opacity or position no more than two weights no letterspacing or small caps no component with a hard-coded value focus-visible is never removed
