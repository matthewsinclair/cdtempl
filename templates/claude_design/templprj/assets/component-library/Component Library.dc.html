two things the neutral kit decides for you, and you should undecide

Radius is 0, so a radio button cannot be round: it is a square with an inner square, distinguished from a checkbox by fill rather than by shape. And the motion rule allows only a 120ms opacity or position change, so there is no rotating spinner — loading is an indeterminate bar. Both are deliberate placeholders, not recommendations. Decide them from the brand and delete this note.
