# exports/

Generated. Never hand-edited.

Both files regenerate from `../Pitch Deck.dc.html`, which is the source of
truth. A hand-edited export is a fork, and the fork wins by accident because it
is the one that gets sent.

| File | State | What it is for |
|---|---|---|
| `pitch-deck.pptx` | present | Editable, native text and shapes, for a venture taking the deck over |
| `pitch-deck.pdf` | **not generated** | The send-ahead version. PDF is a print action taken on the Cdsync side; the source is print-ready and one action away. |

A directory that does not match its own README is the failure `index.md` exists
to prevent, one level down. So the table carries state, and a row is never
listed as present until it is.

The `.pptx` in this directory was generated from the template as the round-two
probe of the export path — it is a deck of blanks, and its only purpose is to
prove the path works end to end. A real venture drop regenerates both.
